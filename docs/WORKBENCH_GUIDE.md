# CrossAIO 工作台功能使用指南

> 工作台地址：`http://localhost:9000/app`（注册 / 登录后进入；免费版每天 5 次调用）
> 每个功能面板顶部都有「❓ 怎么用」折叠指南，本文件为完整版汇总。

---

## 0. 进入工作台

1. 打开 `/app` → 输入邮箱 + 密码（≥8 位）→ 点「注册」或「登录」。
2. 登录后自动进入工作台，右上角显示当前套餐与今日用量（如 3/5）。
3. 页面顶部横幅是「🔗 平台凭证接入中心」，与下方 8 个功能 tab 配合使用。

## 1. 🔗 平台凭证接入中心（顶部横幅，13 平台）

**用途**：把商家自己的平台 API 凭证接入系统，解锁「消息自动导入 / 合规块写回 Listing / 数据回填」。

**使用步骤**：
1. 点顶部**平台胶囊**（⚠ 未接入 / ✓ 已就绪）→ 自动展开并滚动到对应平台的面板。
2. 按面板内「📎 分步指南」前往官方开发者后台申请凭证（如 Amazon SP-API 的 LWA 凭证）。
3. 把凭证粘贴到表单 → 「保存并接入」。凭证以 **AES-256 加密**存储，界面与日志永不回显明文。
4. **eBay 特殊**：走 OAuth 授权，商家不需要自己申请开发者账号——应用凭证由运营方配置后，点「去授权 eBay」跳转完成授权即可。
5. 接错可随时「断开并删除凭证」，或点「↻ 重新检测」刷新状态。

## 2. 📦 产品描述生成器（tab：产品描述）

**用途**：按平台规则一次生成 标题 + 五点描述 + 详情页 + 后台搜索词，11 种语言。

**步骤**：① 填产品名称 + 核心关键词（逗号分隔）→ ② 选目标平台 + 目标语言 → ③ 点「生成产品描述」。
**输出**：标题（含字符数校验）、五点、详情页、搜索词、优化分、平台合规徽章、GPSR 合规块（可直接粘贴进 listing）。
**多国矩阵**：勾选下方平台 → 点「生成多平台矩阵」，一次产出多平台多语言版本；每平台各计 1 次用量，Allegro→波兰语、Otto→德语、Cdiscount→法语、eMAG→罗马尼亚语、TikTok→英语自动匹配。

## 3. 🛡️ GPSR 合规体检（免费，不耗额度）

**用途**：EU 2023/988 强制要求——检测 listing 是否缺欧代 / 当地语言警示语，避免下架。

**步骤**：① 填产品名称 + 关键词（决定命中 CE 类目）→ ② 选平台 → ③ 点「开始免费体检」。
**输出**：风险等级（🔴 高 / 🟡 中 / 🟢 低）、适用 EU 指令、法定检查清单（必查/建议）、所需警示语语言、可粘贴的 GPSR 合规块。
**注意**：合规块要真实写回平台 Listing（Amazon SP-API / eBay OAuth）需先在顶部凭证中心完成该平台接入。

## 4. 💬 AI 客服演示

**用途**：自动回复买家消息，识别意图（物流/退货/投诉/咨询）与情绪，高风险建议转人工。

**步骤**：① 输入买家消息（可附订单号）→ ② 选销售平台（决定 GPSR 披露语言）→ ③ 点「发送」。
**自动能力**：GPSR 安全事件标记 🛡️；EU AI Act Art.50 当地语言 AI 披露；高风险自动 ⚠️ 建议转人工。

## 5. 📥 统一收件箱（13 平台统一）

**用途**：把所有平台的买家会话汇于一处，回复自动经过三重合规工作流（GPSR 安全指引 + Art.50 披露 + 平台语言匹配）。

**步骤**：① 点「载入演示会话」体验统一视图 → ② 用平台筛选胶囊过滤 → ③ 选会话查看消息流并回复。
**注意**：实时消息同步连接器为独立模块——在顶部凭证中心接入对应平台后，买家消息自动导入，无需手动。

## 6. 📣 广告文案生成器

**用途**：Facebook / Google / TikTok 三平台广告文案，字数自动适配。

**步骤**：① 填产品名称 / 目标受众 / 独特卖点 → ② 选平台 → ③ 点「生成广告文案」。
**输出**：主文案 + 标题 + 描述 + CTA + 话题标签，均带字符数。

## 7. 🔄 差评 → Listing 改写（含属性校验）

**差评分析**（每次耗 1 次额度）：① 粘贴差评原文（每行一条）→ ② 可选填星级、材质 → ③ 点「分析差评并生成修复」。
**输出**：问题主题（按严重度分级）+ 每主题的 listing 行动建议 + 可直接粘贴的五点修复文案；命中安全词触发 🚨 GPSR 安全事件预警（含处置步骤与截止提示）。

**属性树校验**（不耗额度）：① 选平台 → 「加载属性树」→ ② 按提示填写 → 「校验属性完整度」。
**输出**：硬阻断（不修必驳回）/ 格式错误 / 建议补齐 + 完整度百分比。

## 8. 📡 Listing 监控（7x24，不耗生成额度）

**用途**：listing 存入监控仓库后，引擎每天自动体检 GPSR 合规与平台规则，生成风险日报。

**步骤**：① 「添加 listing 到监控仓库」填 SKU / 名称 / 平台 / 关键词（建议粘贴现有标题与描述，用于 GPSR 要素检测）→ 「添加并立即体检」→ ② 点「⚡ 立即体检并生成今日日报」（或等定时任务）→ ③ 列表中「详情」看风险项 + 修复建议 + 可粘贴合规块。
**日报**：风险恶化/新增（需处理）、改善（庆祝）；配置 SMTP 后自动邮件推送。
**单条操作**：详情 / 重检 / 删除。

## 常用组合（推荐动线）

| 场景 | 动线 |
|---|---|
| 新品上架 | GPSR 体检（免费）→ 产品描述生成 → 属性树校验 → 添加到 Listing 监控 |
| 接到差评 | 差评分析 → 用五点修复改 listing → 加入监控观察 |
| 买家消息变多 | 凭证中心接入平台 → 统一收件箱统一回复（自动三重合规） |
| 上线前巡检 | Listing 监控 → 立即体检并生成今日日报 → 处理「需处理」项 |
