🤖 Pipeline d'automatisation Détection automatique selon l'abonnement · Traitement automatique

Une fois les identifiants connectés, les problèmes de vos boutiques enchaînent automatiquement les 6 fonctionnalités : la surveillance détecte les risques → les blocs GPSR sont générés pour les risques élevés → les réponses conformes sont rédigées pour les messages acheteurs → suggestions croisées avis négatifs / publicité.

Vérification → bloc de conformité → réponse automatique → suggestions, en un cycle

📦 Générateur de description produit

❓ Mode d'emploi (3 étapes)
  1. Renseignez le nom du produit + les mots-clés principaux (séparés par des virgules, ex : wireless, bluetooth).
  2. Choisissez la plateforme cible et la langue cible (11 langues ; le nombre de caractères du titre est limité automatiquement selon les règles de chaque plateforme).
  3. Cliquez sur « Générer la description produit » → titre / description en cinq points / page détaillée / mots-clés backend + score d'optimisation + bloc de conformité GPSR prêt à coller.
🌍 Matrice multi-pays : cochez les plateformes ci-dessous → cliquez sur « Générer la matrice multi-plateformes » pour produire d'un coup les versions multi-plateformes et multi-langues ; chaque plateforme consomme 1 crédit, Allegro → polonais, Otto → allemand, etc. appariés automatiquement.

Génère titre + description en cinq points + page détaillée + mots-clés selon les règles de chaque plateforme, 11 langues prises en charge.

🌍 Matrice multi-pays européenne (un produit → multi-plateformes, multi-langues)

Chaque plateforme consomme 1 crédit ; Allegro → polonais, Otto → allemand, Cdiscount → français, eMAG → roumain, TikTok Shop → anglais appariés automatiquement.

🛡️ Vérification de conformité GPSR Gratuit

❓ Mode d'emploi (3 étapes)
  1. Renseignez le nom du produit + les mots-clés principaux (qui déterminent la catégorie CE détectée, ex : toy, puzzle).
  2. Choisissez la plateforme cible.
  3. Cliquez sur « Lancer la vérification gratuite » → niveau de risque / directives UE applicables / checklist légale / langues des avertissements requises ; le bloc de conformité peut être copié directement dans la version gratuite.
🔑 Identifiants partagés sur tout le site : pour écrire le bloc de conformité sur le listing de la plateforme, connectez la plateforme une seule fois via le « Centre de connexion des identifiants » en haut de page ; toutes les fonctionnalités (vérification / surveillance / boîte de réception / service client…) réutilisent automatiquement les mêmes identifiants, sans reconnexion par fonction.

Le règlement UE 2023/988 est désormais obligatoire : les listings sans délégué UE ni avertissements en langue locale sont retirés par les plateformes. Saisissez un produit pour obtenir le niveau de risque, les directives applicables et la checklist légale. La vérification est gratuite et ne consomme aucun crédit. Astuce : le bloc de conformité est réellement écrit sur le listing de la plateforme — connectez-le une fois dans le centre de connexion en haut, et toutes les fonctionnalités réutilisent automatiquement les identifiants.

💬 Démo du service client IA

❓ Mode d'emploi (2 étapes)
  1. Saisissez le message de l'acheteur (ex : Where is my order #123-...?), en joignant éventuellement le numéro de commande.
  2. Choisissez la plateforme de vente (qui détermine la langue de divulgation GPSR) → cliquez sur « Envoyer » → l'intention et le sentiment sont identifiés automatiquement, et la réponse conforme est produite ; un risque élevé suggère automatiquement un transfert à un agent.
La réponse est automatiquement assortie de la divulgation IA en langue locale selon l'article 50 de l'EU AI Act ; un incident de sécurité GPSR (surchauffe / étouffement, etc.) est signalé 🛡️ et accompagné des étapes de traitement.

Identifie automatiquement l'intention (livraison / retour / réclamation / question) et le sentiment ; un risque élevé suggère automatiquement un transfert à un agent.

📣 Générateur de textes publicitaires

❓ Mode d'emploi (2 étapes)
  1. Renseignez le nom du produit / la cible (ex : fitness enthusiasts) / l'argument unique de vente.
  2. Choisissez la plateforme (facebook / google / tiktok) → cliquez sur « Générer le texte publicitaire » → texte principal + titre + description + CTA + hashtags, le nombre de caractères s'adapte automatiquement aux limites de chaque plateforme.

Adaptation automatique du nombre de caractères pour Facebook / Google / TikTok.

🔄 Avis négatif → Réécriture du listing

❓ Mode d'emploi (deux modules)
  1. Analyse des avis négatifs : collez le texte des avis négatifs (un par ligne) → renseignez éventuellement la note et la matière → cliquez sur « Analyser les avis et générer la correction » → thèmes de problèmes + texte de correction en cinq points pour chaque thème ; la détection de mots de sécurité déclenche l'🚨 alerte d'incident de sécurité GPSR et les étapes de traitement.
  2. Vérification de l'arbre d'attributs : choisissez la plateforme → cliquez sur « Charger l'arbre d'attributs » → complétez selon les suggestions → cliquez sur « Vérifier la complétude des attributs » → liste des blocages durs / erreurs de format / éléments à compléter, pour éviter un refus dû à un champ obligatoire manquant.
L'analyse des avis négatifs consomme 1 crédit de génération ; la vérification des attributs n'en consomme pas.

Collez le texte des avis négatifs → identification automatique des lacunes du listing → correction en cinq points prête à coller. Consomme 1 crédit de génération.

✍️ Réécriture des réponses aux avis négatifs (réponse publique + message privé)

Génère selon les règles de la plateforme une réponse aux avis négatifs prête à coller : les modèles Amazon / eBay sont commutés automatiquement, un auto-contrôle de conformité est effectué avant diffusion (interdiction de compensations / contreparties contre un avis positif, interdiction de redirection externe), avec traçabilité complète. Génération seule, sans envoi automatique : à vous de confirmer puis copier vers la plateforme. Consomme 1 crédit de génération.

📡 Surveillance des listings 24h/24 et 7j/7

❓ Mode d'emploi (3 étapes)
  1. Dans « Ajouter un listing au dépôt de surveillance » ci-dessous, renseignez SKU / nom du produit / plateforme / mots-clés, et collez de préférence le titre et la description existants (le moteur en détecte les éléments GPSR : délégué UE, avertissements, etc.) → cliquez sur « Ajouter et vérifier immédiatement ».
  2. Chaque jour, cliquez sur « ⚡ Vérifier maintenant et générer le rapport du jour » (ou attendez la tâche planifiée) → le rapport liste les listings dont le risque s'est aggravé, les nouveaux, et les améliorés.
  3. Dans la liste, cliquez sur « Détails » pour voir les risques précis + suggestions de correction + bloc de conformité GPSR prêt à coller ; « Re-vérifier » et « Supprimer » sont disponibles pour chaque ligne.
La vérification repose sur un moteur de règles déterministes, elle ne consomme aucun crédit de génération ; une fois SMTP configuré, le rapport est envoyé automatiquement par e-mail.

Déposez un listing dans le dépôt de surveillance → le moteur vérifie chaque jour la conformité GPSR et les règles de la plateforme → l'évolution du niveau de risque génère un rapport (envoi e-mail SMTP configurable). La vérification repose sur des règles déterministes, elle ne consomme aucun crédit.

📥 Boîte de réception unifiée 13 plateformes unifiées

❓ Mode d'emploi (3 étapes)
  1. Cliquez sur « Charger des conversations de démonstration » pour découvrir la vue unifiée multi-plateformes (en production, les messages acheteurs sont importés automatiquement une fois les identifiants connectés, sans saisie manuelle).
  2. Utilisez la pastille de filtre par plateforme en haut pour ne voir qu'une plateforme.
  3. Cliquez sur une conversation à gauche pour voir le fil de messages → saisissez puis envoyez la réponse ci-dessous ; la réponse traverse automatiquement le triple flux : consignes de sécurité GPSR + divulgation article 50 de l'EU AI Act + appariement de la langue de la plateforme.
🔑 Identifiants partagés sur tout le site : pour la synchronisation en temps réel des messages, connectez la plateforme concernée une seule fois via le « Centre de connexion des identifiants » en haut ; la boîte de réception / le service client / la surveillance, etc. réutilisent automatiquement les mêmes identifiants.

Regroupe en un seul endroit les conversations acheteurs de toutes les plateformes : Amazon / eBay / Allegro / eMAG / Otto, etc. Les réponses traversent automatiquement le flux combiné : consignes de sécurité GPSR + divulgation en langue locale de l'article 50 de l'EU AI Act + appariement automatique de la langue de la plateforme.
Remarque : le connecteur de synchronisation en temps réel (récupération via les API de chaque plateforme) est un module indépendant, pas encore branché ; commencez par « Charger les données de démonstration » pour découvrir la vue unifiée.
