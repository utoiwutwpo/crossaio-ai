📋 Checklist de conformité GPSR

Cochez la conformité GPSR de votre listing
en 5 minutes

Règle (UE) 2023/988 (GPSR) : si un produit est considéré « dangereux », le vendeur doit en informer la Safety Gate de l'UE dans un délai de 15 jours. Plus de 80 % des nouveaux vendeurs n'ont pas encore préparé le délégué UE et les avertissements en langue locale avant la mise en ligne — et ce sont ces items qui sont vérifiés en priorité par les plateformes et les autorités du marché.

✓ 10 items légaux · non un service de consultation juridique · reposez-vous d'abord sur cette checklist

Progression
0 / 10

1 Délégué UE et responsable

Obligatoire pour tout produit entrant en UE. Le nom et le contact du délégué doivent figurer sur le produit, l'emballage ou le listing.
✓
Un délégué UE a été nommé (sponsorisé) Obligatoire
Sans délégué UE, Amazon Europe / Otto / Allegro refusent la mise en ligne. Il existe des services de délégué UE externes (coût ~300–800 €/an). CrossAIO vous aide à générer le bloc de conformité avec le délégué sur le listing.
✓
L'e-mail / le téléphone du délégué UE est affiché sur le listing Obligatoire
Pas seulement dans le document technique : doit être visible sur la fiche produit. Les plateformes demandent en vérification un e-mail de contact valide.

2 Avertissements de sécurité en langue locale

Le GPSR exige des avertissements compréhensibles dans la langue de chaque pays où le produit est vendu. Une version anglaise seule ne passe pas.
✓
Les avertissements sont traduits dans la langue de chaque pays de vente Obligatoire
Exemples : vendu en Allemagne → allemand ; vendu en France → français ; en Italie → italien. CrossAIO génère automatiquement les avertissements dans les langues requises par pays.
✓
Les pictogrammes d'avertissement respectent la norme ISO 7000
⚠ / ♻ / 🔒… les pictogrammes doivent être universels, sans dépendance à la langue. C'est un item souvent oublié.

3 Marquage CE et déclaration UE de conformité

Jouets, électronique, jouets pour l'eau, EPI, machines de petite taille, etc. sont soumis à une directive CE spécifique. Le marquage CE + la déclaration UE de conformité sont indispensables.
✓
Le marquage CE est présent sur le produit (ou l'emballage) Obligatoire
Sans marquage CE, la douane et la Safety Gate de l'UE peuvent refuser la mise sur le marché. CrossAIO identifie automatiquement si votre produit relève d'une catégorie CE.
✓
La déclaration UE de conformité (DoC) est disponible
Généralement fournie par le fabricant. À garder sous la main pour la vérification par la plateforme ou le retrait du marché.

4 Notice et identification du modèle

Le GPSR exige que le produit soit traçable : notice, numéro de modèle, et idéalement photo de l'emballage.
✓
Le listing comporte une notice (ou un lien) dans la langue locale Obligatoire
Pour les jouets et l'électronique, l'absence de notice est le motif n°1 de retrait d'offre. CrossAIO génère un bloc de conformité bilingue EN/FR à coller.
✓
Le numéro de modèle (SKU) est affiché sur la fiche
En cas d'incident, les autorités doivent retrouver le modèle. CrossAIO génère le modèle dans le même bloc de conformité.

5 Informations produits et enregistrement complémentaires

✓
Pour les batteries / appareils électriques, enregistrement EPR / DEEE prévu
France / Allemagne exigent l'immatriculation EPR (batteries et appareils électriques) et le numéro WEEE. C'est un item récurrent dans les vérifications Amazon DE/FR.
✓
Le bloc de conformité GPSR est prêt à coller sur le listing
Il doit rassembler : délégué UE + contact + avertissements multilingues + modèle + déclaration. CrossAIO génère ce bloc automatiquement.
