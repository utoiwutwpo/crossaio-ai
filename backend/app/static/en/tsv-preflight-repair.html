1 Load the marketplace template

No false promises: Error 5995 has three conflicting public explanations. Amazon Seller Forums describe an attempt to change an ASIN brand name, or a flat file using Update so empty columns are treated as deletions. euproof and digicloud9 describe restricted fields being edited without brand-owner rights. Our own article describes missing GPSR compliance data. This tool does not claim that repairing a file makes 5995 disappear. It clears every blocking condition that can be verified before upload, and lists the items that only Seller Central can confirm. Column names are common aliases: check them against your own template and edit them below if needed.
The demo deliberately mixes real-world problems: misuse of Update, a populated restricted brand column, a missing Responsible Person, unsplit address columns, missing local-language warnings and mixed marketplaces. Demo fill values contain the word DEMO and must be replaced before any real upload.
