关于一键合规体检

体检和 /gpsr-check 的免费 GPSR 体检有什么区别？

GPSR 体检只回答「GPSR 合规块怎么写」；一键合规体检是完整闭环：额外覆盖欧代标注位置（产品/包装/Listing 三处统一）、 技术文件档案（Art.9(2)，10 年保存）、监管 48 小时追溯时限与 Safety Gate 15 天上报协议，并把你的欧代台账数据自动嵌入全部交付物。

欧代信息从哪来？会是我的真实数据吗？

是。在工作台「欧代台账」添加欧代并设为默认后，体检报告、合规块、警示语包会自动内嵌你欧代的公司名/地址/邮箱——不再有 [欧代公司名称] 占位符。 未配置欧代时，报告会把「缺欧代」列为 critical 缺项。

技术文件清单包含什么？

8 项：产品描述与规格、风险评估报告、物料清单与供应商信息、检测报告与证书、标签样张与当地语言说明书、 批次追溯记录、符合性声明（DoC）、欧代任命协议。每项标注法定保存年限（10 年/6 年）与提交截止场景。

体检结果能直接贴到平台后台吗？

付费解锁的合规块与警示语包按「可粘贴」标准生成；Starter 及以上还可经回填适配层生成各平台 API 的结构化 payload （真实写回需配置平台凭证，默认 dry-run 不联网）。

这个报告能替代法律意见吗？

不能。报告为工程辅助建议，具体类目适用指令以欧盟官方文本与认证机构意见为准。我们把规则工程化，但不虚报「法律合规认证」。
