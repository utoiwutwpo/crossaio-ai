09 / FAQ

Four common misunderstandings about localization

Can machine translation be used directly?

No, at least review it in your native language and lock the glossary.

Do I need to change the size too?

Yes, the size chart of the EU website is different from that of Asia. If it is not changed, it will be returned.

Does title matter?

Important, Sie / Du can look unprofessional if used incorrectly.

Are minor languages ​​also supported?

Site language is supported, but will be returned for rewriting after random inspection.
