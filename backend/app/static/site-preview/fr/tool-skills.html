09 / FAQ

Quatre questions sur les compétences open source

Peut-il être utilisé commercialement?

Oui, il est sous licence MIT, conservez simplement la déclaration de copyright.

À quelle fréquence la base de règles est-elle mise à jour?

Une fois par semaine, vous pouvez également modifier vous-même le JSON.

Voulez-vous aller en ligne?

Non, exécutez uniquement localement.

Est-ce en conflit avec la version payante?

Il n'y a pas de conflit, les limites des capacités sont les mêmes, la différence réside dans l'hébergement et la collaboration.
