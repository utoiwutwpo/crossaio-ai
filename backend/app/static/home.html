def generate_listing(product, platform="amazon"):
    # 自动匹配平台规则 + 字数硬校验
    rules = PLATFORM_RULES[platform]
    title = ai_write_title(product, max_len=rules.title_max)
    bullets = ai_write_bullets(product, count=rules.bullet_count)
    # GPSR 合规块自动内嵌
    gpsr_block = gpsr_engine.build_block(product.category)
    return Listing(title, bullets, gpsr_block, score=validate(title, bullets))

常见问题

你可能想问

需要绑定我的店铺吗？
不需要。CrossAIO 是独立工作台 — 注册即用，生成的 listing 复制粘贴到任何平台卖家中心即可。我们不会请求你的店铺 API 权限。
GPSR 合规块是什么？
EU 2023/988（通用产品安全法规）已于 2024 年 12 月强制执行：欧盟市场销售的非食品类产品必须有欧盟责任人（欧代）、当地语言安全警示语和合规的制造商信息。CrossAIO 按产品类目自动识别适用指令，生成含欧代占位与当地语言警示语的可粘贴合规块。
生成质量如何保证？
每个平台的标题字数、语言、结构化要求内置为硬校验（如 Otto 70 字符、Allegro 75 字符），生成后自动评分并标记违规项；属性树对 EAN 校验位等做硬阻断，上架前就能发现会被拒审的问题。
免费版和付费版差别？
免费版每天 5 次生成 + 免费合规体检（只报问题）。付费版解锁合规块全文、属性树校验、多平台矩阵，Pro 起含 AI 客服与广告文案。详见定价页。
支持哪些语言？
Listing 生成支持 16 种语言，GPSR 警示语内置 7 种（德/法/意/西/波/罗/英）。语言按平台自动匹配，也可手动指定。
eBay / Cdiscount 等小平台也支持吗？
支持。目前 CrossAIO 已覆盖 13 个平台（Amazon EU+US、eBay、Cdiscount、Otto、Allegro、eMAG、Fruugo、Walmart、Kaufland、Zalando、bol.com、TikTok Shop）。其中 Cdiscount、Allegro、eMAG、Fruugo 在竞品中覆盖率为零，我们率先补齐。
AI 客服需要绑定店铺吗？
第一阶段（开发中）：eBay 卖家授权后，买家消息通过 webhook 推送到 CrossAIO，AI 生成回复草稿，你确认后再发回。不需要第三方工具介入，所有数据在你的 CrossAIO 账户内。
