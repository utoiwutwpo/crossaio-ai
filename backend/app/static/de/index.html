🛡️ GPSR-Compliance-Check Kostenlos

Fügen Sie eine Produktbeschreibung ein — wir scannen auf fehlende GPSR-Info (Hersteller, Warnhinweise, Sicherheit) und liefern einen fertigen Compliance-Block zum Einfügen.

❓ Anwendung (3 Schritte)
  1. Produktname + Kern-Keywords eingeben (bestimmt die zugeordnete CE-Kategorie, z. B. Spielzeug, Puzzle).
  2. Zielplattform wählen.
  3. Auf „Kostenlosen Check starten" klicken → Risikostufe / anwendbare EU-Richtlinien / rechtliche Checkliste / erforderliche Warnhinweis-Sprachen; im Free-Tarif kann der Compliance-Block direkt kopiert werden.
🔑 Zugangsdaten sind kontoübergreifend geteilt: um Compliance-Blöcke zurück auf ein Plattform-Listing zu schreiben, verbinden Sie die Plattform einmalig im „Zugangsdaten-Center" oben, und alle Funktionen (Prüfung / Monitoring / Postfach / Service…) nutzen automatisch dieselben Zugangsdaten — keine erneute Verbindung pro Funktion nötig.

Die EU-Verordnung 2023/988 ist bereits in Kraft: Listings ohne EU-Bevollmächtigten oder Warnhinweise in Landessprache werden von den Plattformen entfernt. Geben Sie das Produkt ein, um Risikostufe, anwendbare Richtlinien und rechtliche Checkliste zu erhalten. Der Check ist kostenlos und verbraucht kein Kontingent. Tipp: um den Compliance-Block tatsächlich auf Plattform-Listings zurückzuschreiben, verbinden Sie einmalig oben im Center — alle Funktionen nutzen es wieder.

💬 KI-Kundenservice-Demo

Fügen Sie eine Käuferanfrage ein — die KI erkennt Absicht und Stimmung und entwirft eine konforme Antwort mit Art.50-Hinweis. Für Automatisierung ist Pro oder höher nötig.

❓ How to use (2 steps)
  1. Käuferanfrage eingeben (z. B. Wo ist meine Bestellung #123-...?), optional mit Bestellnummer.
  2. Verkaufsplattform wählen (bestimmt die GPSR-Hinweis-Sprache) → auf „Senden" klicken → Absicht/Stimmung wird automatisch erkannt, konforme Antwort generiert; bei Hochrisiko wird automatisch die Übergabe an einen Menschen vorgeschlagen.
Antworten tragen automatisch den KI-Hinweis nach EU-KI-Recht Art.50 in Landessprache; GPSR-Sicherheitsvorfälle (Überhitzung/Ersticken usw.) werden 🛡️ mit Bearbeitungsschritten markiert.

Erkennt automatisch Absicht (Versand / Rücksendung / Beschwerde / Anfrage) und Stimmung; bei Hochrisiko wird die Übergabe an einen Menschen vorgeschlagen.

🔄 Negative Bewertung → Listing-Rewrite

Fügen Sie eine negative Bewertung ein — wir finden die Listing-Lücke und generieren eine 5-Punkte-Korrektur, um die Beschreibung zu überarbeiten und Wiederholungen zu vermeiden.

❓ Anwendung (zwei Funktionen)
  1. Bewertungs-Analyse: den Text der negativen Bewertung einfügen (eine pro Zeile) → optional Sternbewertung und Material angeben → auf „Bewertung analysieren und Korrektur generieren" klicken → Problem-Themen + Bullet-Korrekturtext pro Thema; das Treffen von Sicherheitsbegriffen löst einen 🚨 GPSR-Sicherheitsvorfall-Alarm mit Bearbeitungsschritten aus.
  2. Attributbaum-Prüfung: Plattform wählen → auf „Attributbaum laden" klicken → nach Aufforderung ausfüllen → auf „Attribut-Vollständigkeit prüfen" klicken → Liste der harten Blockaden / Formatfehler / Vorschläge, um eine Ablehnung durch fehlende pflichtfeld-pflichtige Kategoriefelder zu vermeiden.
Die Bewertungs-Analyse kostet 1 Generierungs-Credit pro Durchlauf; die Attribut-Prüfung ist kostenlos.

Text der negativen Bewertung einfügen → Listing-Lücken automatisch finden → Bullet-Korrekturen zum Einfügen ausgeben. Kostet 1 Generierungs-Credit pro Durchlauf.

Nur Generierung — kein automatischer Versand; Sie bestätigen und kopieren dann zur Plattform. Kostet 1 Generierungs-Credit pro Durchlauf.

📡 Listing-Überwachung 7x24

Fügen Sie Ihre Listings hinzu — wir führen tägliche Checks durch, markieren GPSR-/Regel-Risiken, generieren Compliance-Blöcke und mailen Ihnen einen Bericht (Pro: täglich, Business: Echtzeit-Alarme).

❓ Anwendung (3 Schritte)
  1. Unten „Listing zum Monitoring-Repo hinzufügen": SKU / Produktname / Plattform / Keywords ausfüllen, idealerweise den aktuellen Titel und die aktuelle Beschreibung einfügen (die Engine erkennt daraus EU-Bevollmächtigten, Warnhinweise und andere GPSR-Elemente) → auf „Hinzufügen und sofortigen Check durchführen" klicken.
  2. Täglich auf „⚡ Check durchführen und heutigen Bericht generieren" klicken (oder auf die geplante Aufgabe warten) → der Bericht listet Listings mit verschlechterten / neuen / verbesserten Risiken.
  3. In einer Zeile auf „Details" klicken, um konkrete Risikopunkte + Korrekturhinweise + einen fertigen GPSR-Block zum Einfügen zu sehen; pro Eintrag „Erneut prüfen" und „Löschen" möglich.
