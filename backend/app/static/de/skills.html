Stellen Sie Ihre eigene KI in 10 Minuten bereit

Die gesamte, von uns in Echtzeit eingesetzte Prüf-Engine: GPSR-Prüfwerkzeug + Plattform-Regelpaket. 100 % Open Source. Kein SaaS-Login, kein Gebührenkonto, keine Nutzungsbeschränkung. Reproduzierbar.

🛡️

GPSR-Compliance-Prüfer

Prüft Produkttitel, erkennt CE-Kategorien, listet Pflichtangaben auf und bereitet einen automatisch generierbaren Compliance-Block vor.

  • CE-Kategorien-Erkennung (Spielzeug, Elektro, Persönliche Schutzausrüstung, Kinder)
  • Warnhinweise in Landessprache (DE/FR/IT/ES/PL/NL/RO)
  • EU-Verantwortlicher + Hersteller + EAN Platzhalter
  • Fehlende Punkte mit Risikostufe, reproduzierbar

Plattform-Regelpaket

13 europäische + US-Plattformen: Titellimits, Pflichtsprachen, harte Verbote, Attribute — als JSON-Rohdatei, direkt in Ihre KI einspielbar.

  • Amazon EU/US, eBay, Allegro, Otto, Cdiscount, eMAG, Kaufland, bol.com, Zalando, Fruugo, TikTok Shop, Walmart
  • Titel-Bullet-Beschreibungs-Zeichenlimits
  • Landessprachen-Pflicht + Harte Verbote (Loi Toubon)
  • CE-Kategorien → Plattform-Mapping

Minimale Vorbereitung

Klonen → einstellen → starten

Terminal
# GPSR-Prüfer klonen
git clone https://github.com/crossaio/gpsr-checker.git
cd gpsr-checker

# API-Schlüssel setzen (OpenAI / Anthropic / DeepSeek alle möglich)
export OPENAI_API_KEY=sk-...

# Starten
python gpsr_check.py --title "Kids Building Blocks Toy" \
                --keywords "toy,puzzle,kids" \
                --platform otto
