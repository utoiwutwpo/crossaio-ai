GPSR-Compliance-Checker

skills/gpsr-compliance-checker/

Übergibt der KI die Einstell-Checkliste der EU 2023/988 (Allgemeine Produktsicherheitsverordnung): Sie erkennt, ob ein Produkt in eine CE-Kategorie fällt, prüft Punkt für Punkt Angaben zum EU-Verantwortlichen, Sicherheitswarnhinweise in der Landessprache, CE-Kennzeichnung, Bedienungsanleitung und Modellkennzeichnung und erzeugt einen mehrsprachigen Compliance-Block, der direkt ins Listing eingefügt werden kann.

  • Automatische Erkennung von 7 CE-Kategorien (Spielzeug / Elektronik / Textilien / Kinderprodukte usw.)
  • EU-27-Staaten + Vereinigtes Königreich → automatische Zuordnung der Hinweissprachen (DE/FR/IT/ES/NL/PL…)
  • Erkennung von 5 gesetzlich vorgeschriebenen Elementen: EU-Verantwortlicher / Warnhinweise / Bedienungsanleitung / Modell / CE-Kennzeichnung
  • Erzeugt einen einfügbaren Compliance-Block mit Platzhalter für den EU-Verantwortlichen und Warnhinweisen in Landessprache
  • Integrierte Datenbank mit 69 Sicherheitsbegriffen (bilinguale EN/DE), dieselbe Quelle wie die Warnung vor sicherheitsrelevanten Bewertungen

Europäische Plattform-Regeldatenbank

skills/eu-marketplace-rules/

Schnellnachschlag zu den Einstellregeln von 13 europäischen und transatlantischen E-Commerce-Plattformen: maximale Titelzeichen, erforderliche Sprachen, GPSR-Punkte, abgedeckte Länder. Fragen Sie die KI vor dem Schreiben Ihres Listings und vermeiden Sie häufige Nacharbeit wie „Bei Allegro vergessen, ins Polnische zu übersetzen" oder „Bei Otto wurde der Titel wegen Zeichenüberschreitung abgelehnt".

  • Amazon EU + US / eBay / Cdiscount / Otto / Allegro / eMAG
  • TikTok Shop / Fruugo / Walmart / Kaufland / Zalando / bol.com
  • Pro Plattform: Titelzeichen / Bulletpoints / Suchbegriff-Limit / Standardsprache
  • 9 häufige Fallstricke: EAN als eindeutiger Schlüssel, Polnisch-Pflicht, zDirect-Onboarding-Prüfung…
  • Regeldaten werden automatisch aus der Online-Engine exportiert (platforms.json) und laufen nie ab
13 Plattformen · laufend aktualisiertRegelkarten zweisprachig EN/DEMIT

Why Open Source

Warum kostenlos und quelloffen?

Compliance ist ein Vertrauensgeschäft — nur wenn Regeln transparent einsehbar sind, vertrauen Sie dem Tool Ihre Listings an.

🔍

Regeln vollständig transparent

7 CE-Kategorien und jede Warnhinweis-Zuordnung liegen als lesbare JSON-Datei im Repository — keine Blackbox-Entscheidungen. Sie finden einen Fehler in den Regeln? Öffnen Sie einfach ein Issue oder einen PR.

🔄

Gleiche Quelle wie die Online-Engine

Die Skill-Daten werden von tools/export_skill_data.py automatisch aus der CrossAIO-Backend-Engine exportiert — ändern wir Regeln, aktualisiert sich der Skill, es gibt keine zwei unterschiedlichen Fassungen.

🚀

Sie möchten vollautomatisch? Upgrade auf SaaS

Der Skill ist die manuelle Prüfung. Die SaaS-Version ergänzt 7×24-Listing-Monitoring, tägliche Risikoberichte, die 13-Plattform-Massen-Generierung und den geschlossenen Kreislauf für Sicherheitswarnungen bei Bewertungen.
