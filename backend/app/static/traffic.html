GA4 状态

· 2026-11-07 新口径：UA 三态分类 —— human（完整浏览器指纹 + 文档导航请求头）、 bot（搜索引擎/抓取器）、probe（空 UA、健康检查、自建验证脚本、无浏览器指纹）。 只有 human 计入真人指标，自检请求不再灌水。
· 渠道归因：URL 上的 utm_source/medium/campaign/content 写入 PV 与 30 天 caio_attr cookie；无 UTM 时按 Referer 推断（reddit / sellerforum / facebook / google …）， 都没有则记 direct。独立访客用匿名 caio_vid cookie，不存 IP 原文。
· 转化事件（体检、注册、生成、订阅）按 utm_source 归到渠道，用来判断「推广有没有带来真实动作」， 而不是只看总 PV。看板页 /traffic 自身不计入。
· Token 只保存在本浏览器 localStorage，不进仓库；看板已设 noindex，不进 sitemap。
· GA4 为可选增强：Render 配置 GA4_MEASUREMENT_ID=G-XXXXXXXXXX 并重启后全站注入 gtag；未配置时零第三方脚本。
· 时间均为 UTC（北京时间 = UTC + 8 小时）。Render 免费层 SQLite 在临时磁盘，重新部署会清空历史 PV， 长期趋势需接外部 Postgres 或 GA4。
